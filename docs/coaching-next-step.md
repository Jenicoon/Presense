# 결과를 받은 뒤 필요한 다음 행동 선택

새 페이지·도구·녹화 모드를 추가하지 않는다. 기존 항목별 확인 뒤에 다음 행동 하나를 제안하고, 기존 버튼으로 실행한다.

- 자료나 같은 내용·환경 확인이 부족하면 비교 판정을 보류하고 조건을 다시 확인한다.
- 한 번의 미완료만으로 방법을 바꾸지 않는다. 같은 방법과 같은 확인 기준의 최근 두 시도에서 같은 항목이 계속 남았을 때 기존에 지원하는 다른 방법도 후보에 넣는다.
- 말하기나 두 표정 시도는 했지만 고르는 단계가 남았다면, 기존 영상을 먼저 비교하는 선택도 제공한다. 판단이 어려웠다는 답도 기존 자료를 먼저 확인할 수 있다.
- 사용자가 목표를 달성했다고 확인한 경우에만 보고서에 이미 근거가 있는 다음 목표를 검토한다. 새 문제를 만들지 않고 마무리도 선택할 수 있다.

서버가 관측 품질·버전·확인 결과로 허용 후보를 제한한다. 하나의 선택만 필요한 경우 LLM을 호출하지 않는다. 여러 유효 후보 중 판단이 필요한 경우에만 실제 AI가 하나와 양 언어 이유를 선택한다. 추천에는 사용자의 자기 확인과 반복 기록의 근거 ID가 필요하며, 허용 행동·지표 방향·수치를 만들어낼 수 없도록 형식 검사와 별도 의미 검증을 거친다. 입력은 고정된 확인 항목, 그 답, 허용 방법과 필요한 보고서 관측 문맥으로 제한한다. 세션·연습·계정 ID, 파일명, 미디어와 자유 대화는 이 선택 호출에 보내지 않는다.

추천은 실행 명령이 아니다. 기존 채팅에서 한 버튼을 먼저 보여주며, 사용자가 선택해야 실행한다. 원하면 다른 행동을 선택할 수 있다. 모델 응답이나 검증에 실패해도 이미 입력한 확인 결과를 저장하고 수동 버튼을 유지한다. 답과 문맥이 그대로면 저장된 추천을 복원해 언어 전환·새로고침 때 다시 생성하지 않는다.

기존 비교 화면으로 돌아가 같은 촬영의 답을 수정할 수 있다. 서버가 저장한 직전 행동이 비교 재열기인지 확인하며, 같은 답의 중복 제출과 다른 촬영 ID는 거부한다. 이전 답·비교 결과는 reviewHistory에 보존한다. 답 수정은 새 촬영 횟수로 세지 않고 원본 측정값도 변경하지 않는다.

검증: 서버 179개·프론트 53개, 타입 검사와 실행 빌드. 실제 Luxia는 합성 exact7 분석에서 두 방식으로 말하기는 실행했고 방식 고르기는 남았다는 답을 보고 재촬영 대신 기존 영상 재확인을 선택했다. 실제 요청과 응답은 Git 제외 local-validation/next-coaching-step-20261104에 저장했다. 거부된 응답도 보존했다. StressID, 미디어, 계정 정보와 실제 세션 ID는 전송하지 않았다. 기존 보고서·초기 측정·점수 계산과 기록 저장 구조는 유지하며 새 DB 마이그레이션은 필요하지 않다.

한계: 달성은 사용자의 영상 확인 결과와 자료 조건에 따른 기록이다. AI가 영상·발화 내용을 직접 이해해 전달력을 평가하는 기능이 아니다. 실제 사용자 카메라와 운영 Supabase 실계정 검증은 별도다.
